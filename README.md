# DrCoxinha_ Client  (Fabric 1.21.11)

Etapa 1: base, config e menu (PvP / Finder). Os 11 modulos ja aparecem no menu com suas
configuracoes; a logica de cada um entra nas Etapas 2 (PvP) e 3 (Finder).

## Como gerar o .jar pelo GitHub (sem instalar nada)
1. Crie um repositorio novo no GitHub (pode ser privado).
2. Envie TODO o conteudo desta pasta, incluindo a pasta oculta `.github`.
3. Abra a aba **Actions** -> workflow "Build DrCoxinha_ Client" -> execute (ou ele roda sozinho no push).
4. Quando terminar (2-3 min), entre na execucao e baixe o artefato **DrCoxinha_Client** (um .zip com o .jar dentro).

## Instalar
- Fabric Loader 0.18.1+ e **Fabric API** para 1.21.11
- Coloque `DrCoxinha_Client-1.0.0.jar` na pasta `.minecraft/mods`
- No jogo: **Shift Direito** abre o menu

## Config
`.minecraft/config/drcoxinha_client.json`
